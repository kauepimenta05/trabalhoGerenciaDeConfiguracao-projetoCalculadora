Calculadora Java
Objetivo do Projeto
Desenvolver uma calculadora em Java capaz de realizar operações matemáticas básicas (soma, subtração, multiplicação e divisão), aplicando conceitos de Gerência de Configuração de Software utilizando Git e GitHub.
